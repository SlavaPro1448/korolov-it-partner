# KI-Übersetzer для церковного собрания (RU ↔ DE)

Отдельный маленький сервер (не часть сайта, не Vercel). Один оператор открывает страницу
`/operator?key=…` на ноутбуке в зале и даёт доступ к микрофону; сервер режет речь по паузам,
распознаёт (`gpt-4o-transcribe`, язык определяется сам), переводит текстом (`gpt-5.4-mini`,
без reasoning) и озвучивает перевод (`gpt-4o-mini-tts`) один раз на всех. Слушатели открывают
`/?key=…`, выбирают язык и получают субтитры + голос по WebSocket.

Аудио не сохраняется, текст в лог не пишется (только тайминги и длины).

## Деплой

```bash
bash uebersetzer/deploy.sh
```

Скрипт печатает две ссылки (оператор и слушатели). Поменять ключ OpenAI:
`ssh -t scribe /opt/bots/uebersetzer/set-secrets.sh`.

## Локально

```bash
cd uebersetzer && npm install
OPENAI_API_KEY=… OPERATOR_KEY=op LISTEN_KEY=lk npm start
# http://localhost:8080/operator?key=op  и  http://localhost:8080/?key=lk
```

## Цена и задержка (оценка)

За трёхчасовое собрание при ~125 мин речи: распознавание ≈ $0.75, перевод ≈ $0.30,
озвучка ≈ $1.9, итого ≈ $3. Субтитры через 1.5–3 с после конца фразы, голос следом.

## Этапы

1. Проверка в зале с ноутбука (встроенный микрофон) — текущее состояние.
2. Звук автоматически из `gemeinde-icecast` внутри docker-сети (без ноутбука).
3. Ссылка в приложении общины, потоковое распознавание, словарь.
