# OG image TODO

Эта папка содержит языковые Open Graph изображения `1200x630` для шаринга в WhatsApp / Telegram / LinkedIn.

## Файлы

- `og-default-de.jpg` -> `Korolov IT-Service — Websites & IT-Support in Leverkusen`
- `og-default-ru.jpg` -> `Korolov IT-Service — Сайты и IT-поддержка в Леверкузене`
- `og-default-ua.jpg` -> `Korolov IT-Service — Сайти та IT-підтримка в Леверкузені`

## Вариант 1: Figma

1. Создайте Frame `1200x630`.
2. Фон: используйте фирменные цвета (рекомендуется #0F2742 с мягким градиентом).
3. Добавьте логотип/название и соответствующий языковой текст из списка выше.
4. Оставьте безопасные поля минимум 60 px от краев.
5. Экспортируйте каждый макет как JPG (качество 80-90%).
6. Сохраните в эту папку с точными именами файлов.

## Вариант 2: Bannerbear

1. Откройте [Bannerbear](https://www.bannerbear.com).
2. Создайте шаблон `1200x630`.
3. Добавьте текстовый слой и три языковых варианта текста.
4. Сгенерируйте три изображения через API/интерфейс.
5. Скачайте JPG и сохраните в эту папку с точными именами файлов.

## Проверка

- Используйте абсолютные URL:
  - `https://korolov-it-service.de/og/og-default-de.jpg`
  - `https://korolov-it-service.de/og/og-default-ru.jpg`
